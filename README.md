# Labo — лаборатория моделирования систем Акулы

Отдельный репозиторий для воспроизводимых математических и имитационных экспериментов: сети, перемещения устройств, отключения и отложенная доставка. Это **не отдельный пользовательский продукт** и не часть исполняемого ядра Акулы.

Проектируемый движок: Rust, виртуальное время, воспроизводимый seed, пространственные индексы вместо полного перебора пар, экспериментальные сценарии для зданий и открытых площадей.

Источники требований: [AK-MSG-SIM-2000](https://app.notion.com/p/40032a84beec8113a9e0ddd204081f50) и [AK-MSG-CORE-01](https://app.notion.com/p/40032a84beec81919ec8df2e31056543).

Основная ветка содержит описание и принятые исходные условия. Реализацию и испытания вести в отдельных ветках до проверки.
