# LABO — изолированная лаборатория моделирования Акулы

LABO исследует масштабируемость, связность, движение и доставку данных при отказах. **Это не самостоятельный мессенджер** и не часть исполняемого ядра Акулы. Математика живёт в [calex794/labo](https://github.com/calex794/labo); проверенные инженерные выводы и тестовые случаи можно отдельно переносить в Akula/WOW/Roha.

## Быстрый запуск

Нужен стабильный Rust (`cargo`). Из корня репозитория:

```bash
cargo test --all-targets
cargo run --release -- --map building --mode hybrid --devices 2000 --messages 5000 --steps 120 --seed 21
cargo run --release -- --map building --mode exclusive --devices 200000 --messages 25000 --steps 180 --seed 21
cargo run --release -- --map plaza --mode ble --mobility all --outages periodic --devices 200000 --messages 25000 --steps 180 --seed 22
cargo run --release -- --devices 2000 --messages 3000 --steps 120 --matrix > matrix.ndjson
```

`--matrix` выдаёт **36 строк JSON**: 4 состава радиосвязи × 3 уровня движения × 3 режима обрывов. Каждая строка — самостоятельный синтетический опыт, результаты — не измерения физических устройств.

| Параметр | Варианты |
|---|---|
| `--map` | `building` (5 этажей × 70 кабинетов, 5 лестниц), `plaza` (площадь 500 × 500 условных метров) |
| `--mode` | `wifi`, `hybrid`, `ble`, `exclusive` (Wi-Fi **или** cellular **или** BLE) |
| `--mobility` | `static`, `quarter`, `all` |
| `--outages` | `never`, `once`, `periodic` |
| `--devices` | от 2 до 1 000 000 виртуальных устройств |
| `--messages` | число сообщений (не контейнеров) |
| `--steps` | длина опыта в виртуальных шагах |
| `--ttl`, `--contact-probes`, `--relay-percent`, `--seed` | срок хранения, число контактных попыток, доля добровольных посредников, воспроизводимость |
| `--ip-interconnect` | явное допущение IP-пути Wi-Fi ↔ сотовая сеть; **не** создаёт мост Bluetooth ↔ IP |

## Почему 200 000 устройств — не 200 000 контейнеров

Логические участники — структуры в памяти Rust. Пространственный индекс по ячейкам и ограниченное число предложений контакта исключают полный перебор каждой пары. Порядок вычислений — `O(T·(N + M·K))`, где N — число устройств, M — число сообщений, K — заданный предел проб соседей, T — время в виртуальных шагах.

**Ограничения v0:** идеализированный общий Wi-Fi, параметрическая BLE-близость, один носитель каждого сообщения, случайный выбор добровольного посредника, упрощённые обрывы питания и маршруты движения. Нет реальных Bluetooth-замеров, фоновых ограничений смартфонов, подписанных подтверждений WOW, очередей SQLite или полноценной физической модели радиоканала. В JSON отчёта стоит `"claim":"synthetic-not-measured"`.
