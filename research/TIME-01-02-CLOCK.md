# LABO TIME-01/02 — drift и восстановление без RTC

Спецификация: https://app.notion.com/p/40232a84beec8160aab4e1041cdb103a

TIME-01: детерминированный расчёт верхней границы ошибки RTC для 1/7/30/90/365 суток, 1/10/50/100 ppm, ротации 10/20/60/1440 минут. Проверка точного и соседнего временного окна по всем фазам периода. Это **расчёт**, не измерение физических часов, и предполагает, что RTC продолжает ходить.

TIME-02: сохранённая нижняя граница UTC, версия поколения, внешний checkpoint, ровно один логический C-слот. После потери RTC ставим CLOCK_UNCERTAIN: временную рекламу и истекающие FETCH выключаем, бессрочные операции допустимы только по отдельным правам и защите. При возврате RTC ниже сохранённой отметки или при обнаруженном откате checkpoint — CLOCK_CONFLICT. Не восстанавливаем UTC из одной подписи соседа.

Подписанное Ed25519 свидетельство использует nonce, поколение, checkpoint и временной интервал. Его проверка **не доказывает истинность UTC**, что проверяется отрицательным тестом. В эксперименте нет реальных WAL/SQLite, блокировок файлов, NTP, Roughtime, cryptographic W3/W4 либо аппаратных RTC.

Код в experiments/time01-time02-clock; узкий CI .github/workflows/time01-time02-clock.yml; JSON/CSV/Markdown только после проверенных GitHub Actions.
