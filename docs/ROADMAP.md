# План развития LABO — независимой лаборатории

Один репозиторий — множество исследовательских задач. Отдельно от приложения Akula: `src/` (исполняемая модель), `docs/` (математика), `scenarios/` (входные условия будущего), `results/` (генерируемые отчёты, не коммитятся), GitHub Actions (регрессии).

| Этап | Измеримый результат | Статус |
|---|---|---|
| L0: каркас | Rust CLI, 2 карты, 4 режима связи, 3 перемещения × 3 отказа, JSON | Код в ветке; CI требуется |
| L1: базовая воспроизводимость | несколько seed, автоматические проверки целостности, 200k логических устройств без N² | Код в ветке; CI требуется |
| L2: радиофизика | параметрические потери на двери, стены и этажи; вероятность обнаружения BLE; реальные интервалы связи | Не реализовано |
| L3: движение | рабочий день, плотность потоков, движение по лестницам и коридорам, SocioPatterns-трассы | Не реализовано |
| L4: сетевые отказы | раздельный Wi-Fi/IP/BLE, NAT, точки доступа, выход приложения в фон, потеря питания | Не реализовано |
| L5: DTN | несколько стратегий, лимиты копий, срок хранения, очередь на диске, периодическая связь, отдельные ACK | Не реализовано |
| L6: масштабирование | сравнение 2k/20k/200k, p50/p95 времени/памяти, длительные 36×несколько seed | Не проверено |
| L7: связь с Акулой | модель событий контракта WOW/Core (без импорта экспериментального движка в Akula), контрпримеры для PR | Не реализовано |

Правила:
- все выводы сопровождаются конфигурацией, seed, SHA модели, областью достоверности;
- цифровая близость ≠ реальная BLE-связь, локальная Wi-Fi ≠ интернет;
- отсутствующий BLE↔IP шлюз не появляется при движении;
- нечестно объявлять доставку по квитанции посредника;
- главное приложение Akula **не импортирует** экспериментальный движок по умолчанию;
- benchmark и моделирование в Labo, исправленные подтверждённые интерфейсы — отдельными PR в Akula/WOW/Roha.
